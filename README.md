## ✨ 기능

- ⏱ **25분 집중 / 5분 휴식** — 기본 포모도로 사이클
- 🎨 **빈티지(레트로) 디자인** — 감성적인 집중 환경
- 🖥 **데스크톱 네이티브** — Windows / macOS 설치형 앱
- 🔔 **알림** — 타이머 종료 알림으로 휴식 안내
- 🆓 **무료** — 광고 없음, 가입 없음

## 📚 포모도로 기법이란?

포모도로 기법(Pomodoro Technique)은 25분 동안 한 가지 일에 집중하고 5분 쉬는
시간 관리법입니다. 뽀모도로, 뽀모, Pomodoro Timer, 공부 타이머, 집중 타이머,
작업 관리, 시간 관리 — 어느 이름으로 검색하든 이 앱을 찾을 수 있습니다.
